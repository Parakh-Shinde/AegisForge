# v0.10 adapted holdout-v2 regression policy

The 24 cases in `adapted_holdout_v2.json` are derived from the already executed
holdout-v2 corpus. They are therefore classified as **adapted regression data**,
not independent holdout evidence.

The v0.10 gate requires both the rule-only and hybrid paths to classify every
case correctly: precision, recall, and F1 must remain 1.0, while false-positive
and semantic-provider-failure rates must remain 0.0. The corpus-size check
prevents cases from being silently removed.

The original `holdout_v2.json`, evaluation freeze, and first-run report remain
immutable historical evidence. CI runs only this adapted copy.
